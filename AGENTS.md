# Agent instructions

## Slides (`slides.md`, Slidev)

- Prefer markdown-friendly tools over hand-written HTML/SVG. For diagrams use
  Mermaid code fences (natively supported by Slidev) so the source stays short,
  readable and easy to diff.
- Use a pre-rendered image under `images/` only when Mermaid can't express the
  diagram well, and say why.
- Write slide titles in Title Case (short words like "of", "to", "and", "the"
  stay lowercase). Keep `isx` lowercase and write `OpenShell` in CamelCase.
  Leave text in backticks and code comments as they are.
